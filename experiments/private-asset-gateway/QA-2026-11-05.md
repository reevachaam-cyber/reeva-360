# Private asset gateway: isolated contract QA

Date: 2026-11-05

## Outcome
**13/13 checks passed** using the actual `experiments/private-asset-gateway/worker.mjs` source in an isolated JavaScript execution environment with mocked `Request`, `Response`, `Headers`, R2 bucket, KV namespace, and a deterministic stub for SHA-256.

Cases covered:
1. Valid link serves allowed `index.html` (HTTP 200).
2. Unknown share token (404).
3. Disabled token (404).
4. Consent not confirmed (404).
5. Malformed R2 prefix (404).
6. Too-short token (404).
7. Percent-encoded path slash rejected (404).
8. Path traversal rejected (404).
9. Unlisted file extension rejected (404).
10. POST rejected (404).
11. Missing tile returns 404.
12. HEAD responds without object body.
13. Missing Workers bindings fail closed (503).

**Important test qualification:** These checks are not a Cloudflare Workers runtime test, not an integration test with real R2/KV, and not proof that 360° images render. Token hashing was stubbed with an input-dependent deterministic digest in this execution environment. The existing committed Node test suite `worker.test.mjs` has not been executed directly with `node --test` in this QA turn.

## Release blockers
- Confirm resource bindings, R2 private access and object path mapping in a deployed isolated Cloudflare preview.
- Verify no public `r2.dev` or custom-domain access is enabled on the bucket.
- Confirm quotas and billing for Workers, R2, and KV at the actual account; Marzipano makes numerous tile requests, potentially one KV read per tile.
- Measure KV eventual consistency for revocation; do not claim instantaneous global disabling.
- Implement optional password enforcement at server-side before issuing access to any protected media, if approved.
- Implement authenticated admin uploader, token issuance, and disabling, not merely the read-only Worker.
- Obtain customer-owner media consent before upload.
- Production Wix site and existing public A28 tour must remain unchanged until explicit release approval.

## Current status
Cloudflare selected as proposed architecture, **not provisioned or deployed**. No new billing initiated. No private homeowner media uploaded. Static demo A28 site continues to work unchanged.
